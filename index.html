REPS
POLITIQUE DE CONFIDENTIALITÉ

On ne collecte rien.

Version 1.0 Mise à jour · 16 mai 2026 Applicable à toute version de l'app REPS

REPS est une application de suivi d'entraînements de musculation conçue pour fonctionner entièrement hors-ligne. Cette page décrit comment vos données sont traitées — c'est-à-dire, en pratique, comment elles ne sortent jamais de votre téléphone.

EN UNE PHRASE

REPS ne collecte aucune donnée personnelle, ne se connecte à aucun serveur, n'utilise aucun service tiers de tracking et n'affiche aucune publicité.

1. Données stockées localement

Toutes les données que vous saisissez dans l'app — sessions d'entraînement, exercices, séries, poids, durées — sont stockées uniquement sur votre appareil, dans la base de données interne de l'app.

Ces données ne sont jamais transmises à un serveur, à l'éditeur ou à un tiers. Si vous désinstallez l'app, ces données sont supprimées avec elle (sauf si vous avez exporté une sauvegarde au préalable — voir section 3).

2. Permissions demandées

L'app peut demander les permissions suivantes pour fonctionner :

  • Stockage — pour lire et écrire les fichiers de sauvegarde JSON que vous choisissez de créer ou d'importer. L'app n'accède à aucun autre fichier.
  • Partage — pour envoyer une sauvegarde via une autre application (par exemple : email, messagerie, cloud personnel) à votre demande explicite.

Aucune autre permission n'est demandée. L'app ne demande pas l'accès au réseau, à la localisation, à la caméra, aux contacts, etc.

3. Sauvegarde & restauration

Vous pouvez à tout moment exporter vos données dans un fichier JSON via le menu Paramètres → Sauvegarde. Ce fichier est créé sur votre appareil — c'est vous qui décidez s'il reste localement, est envoyé sur votre cloud personnel, ou partagé avec quelqu'un.

L'éditeur de l'app n'a aucun accès, ni visibilité, sur ces fichiers de sauvegarde.

4. Analytique, tracking, publicité

REPS n'utilise pas :

  • Aucun outil d'analytique (pas de Google Analytics, Firebase Analytics, Mixpanel, etc.)
  • Aucun outil de crash reporting tiers
  • Aucun SDK publicitaire
  • Aucun pixel de tracking, identifiant publicitaire ou cookie
  • Aucune intégration de réseau social

5. Comptes utilisateurs

L'app ne propose pas la création de compte. Aucune adresse e-mail, identifiant ou mot de passe n'est demandé. Vous utilisez l'app de manière complètement anonyme.

6. Enfants

L'app n'est pas destinée spécifiquement aux enfants, mais étant donné qu'aucune donnée personnelle n'est collectée, elle peut être utilisée par tout public sans risque pour la vie privée.

7. Modifications de cette politique

En cas de modification (par exemple si une future version de l'app introduit une fonctionnalité en ligne optionnelle), cette page sera mise à jour, et la date de mise à jour en haut de la page sera modifiée. Si la modification concerne une collecte de données, elle sera communiquée explicitement dans l'app avant d'être effective.

8. Vos droits (RGPD)

Le RGPD (règlement européen sur la protection des données) vous donne plusieurs droits sur vos données personnelles. Comme REPS ne collecte aucune donnée :

  • Il n'y a rien à consulter — vos données sont déjà sur votre appareil.
  • Il n'y a rien à supprimer — désinstaller l'app supprime tout.
  • Il n'y a rien à porter — vous exportez vos données vous-même en JSON.

9. Contact

Pour toute question concernant cette politique de confidentialité, vous pouvez écrire à bletrazer@gmail.com.
